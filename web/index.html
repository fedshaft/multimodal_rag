The Singularity Sequence

A step-by-step account of how a natural-language inquiry navigates dual embedding spaces, ordinal rank fusion, and vision-language synthesis.

01
CORPUS DECONSTRUCTION

Ingestion & Figure Extraction

PyMuPDF systematically extracts text blocks bounded into 300-word windows with 50-word overlaps to preserve cross-boundary semantics. Concurrently, all raster illustrations and vector slide compositions are rasterized at 150 DPI.

CHUNK_WORDS: 300 OVERLAP: 50 DPI: 150 TOOL: PyMuPDF
02
REPRESENTATION LEARNING

Dual-Space Vector Encoding

Passages are vectorized into 384-dimensional dense vectors via BAAI/bge-small-en-v1.5. Extracted figures and full slide renders are encoded into a joint 512-dimensional manifold using OpenAI's CLIP ViT-B/32, projecting visual concepts into semantic text reach.

TEXT: BGE-small (384d) VISION: CLIP ViT-B/32 (512d) STORAGE: Chroma DB
03
TRI-MODAL RETRIEVAL

Parallel Candidate Dispatch

Upon query submission, three parallel search paths execute: sparse BM25 keyword matching for exact lexical tokens, dense BGE cosine search for paraphrased concepts, and CLIP visual similarity for diagrammatic alignment.

BM25: ~3.0 ms BGE DENSE: ~9.2 ms CLIP VISUAL: ~18.5 ms
04
RANK HARMONIZATION

Reciprocal Rank Fusion (RRF)

Raw scores across BM25 (unbounded log-odds [0, 30]), BGE cosine [0, 1], and CLIP cross-modal scores [0.15, 0.35] cannot be directly averaged. RRF fuses them purely through ordinal rank positions: RRF(d) = ∑ [w_m / (60 + rank_m(d))].

K_RRF: 60 SCALE: Invariant MERGE TIME: 0.05 ms
05
CROSS-ATTENTION VERIFICATION

Cross-Encoder Deep Reranking

The top 60 shortlist candidates undergo joint cross-attention through BAAI/bge-reranker-base. Every token of the query inspects every token of the candidate passage simultaneously, boosting Top-5 Hit rate from 73.0% to 81.1%.

MODEL: BGE-Reranker-Base CANDIDATES: Top-60 HIT@5: 81.1%
06
GROUNDED SYNTHESIS

Local Vision-Language Generation

The final curated package of text passages and high-resolution diagrams is passed to a local vision-language model (Qwen2.5-VL), which writes an empirical response with strict citation accountability.

MODEL: Qwen2.5-VL (Local) TEMPERATURE: 0.0 (Greedy) ZERO CLOUD APIS

Cohen's Kappa Analysis (κ = 0.812)

κ = 0.812

To ensure the benchmark questions were objectively categorized by modality, two independent annotators categorized all 40 questions into Text, Figure, Both, or None. The observed agreement Po = 0.875 against chance agreement Pe = 0.334 establishes near-perfect agreement according to the Landis & Koch standard.

κ = (P_o - P_e) / (1 - P_e) = (0.875 - 0.334) / (1 - 0.334) = 0.812

// TECHNICAL APPENDIX

System Architecture & Theory

Mathematical formulations, encoder projection manifolds, scale-invariant rank fusion, and consumer hardware latency profiles.

REPRESENTATION THEORY

Joint Vision-Language Manifold

Natural language queries and pixel diagrams reside in fundamentally disconnected dimensional spaces. CLIP ViT-B/32 projects both modalities into a shared unit hypersphere via dual contrastive objectives.

S_{cos}(q, img) = \frac{\mathbf{E}_{text}(q) \cdot \mathbf{E}_{img}(img)}{\|\mathbf{E}_{text}(q)\| \|\mathbf{E}_{img}(img)\|}

Queries such as “What does the page table diagram show?” map into the vector neighborhood of the slide schematic directly, bypassing brittle OCR text recognition.

FUSION MATHEMATICS

Scale-Invariant Reciprocal Rank Fusion

BM25 scores follow an unbounded log-odds scale [0, 30]; dense text cosine similarities span [0, 1]; CLIP cross-modal scores concentrate within [0.15, 0.35]. Linear score interpolation causes degenerate mode collapse.

\text{RRF}(d) = \sum_{m \in M} \frac{w_m}{k_{rrf} + r_m(d)}, \quad k_{rrf} = 60

RRF enforces scale invariance by operating strictly on ordinal rank indices r_m(d), allowing lexical exactness and semantic abstractions to coexist symmetrically.

DEEP VERIFICATION

Cross-Attention Self-Verification

While bi-encoders compute representations in isolation for extreme speed, cross-encoders compute all-to-all attention between query tokens and candidate tokens simultaneously.

\text{Score}(q, d) = \text{MLP}(\text{CrossAttention}([\text{CLS}], q_1..q_n, [\text{SEP}], d_1..d_m))

Running cross-encoders across all 2,431 chunks is prohibitive (~14s on CPU). By gating the cross-encoder strictly to the top-60 shortlist, execution finishes in ~1.0s while achieving 81.1% Hit@5.

ENGINEERING ARCHITECTURE

Offline Ingestion vs. Online Query

The system adheres to a strict two-phase boundary. Compute-intensive vector generation runs once ahead of time; live user inquiries execute in milliseconds on standard consumer CPUs without paid cloud APIs.

\text{Total Query Latency} = t_{BM25} (3ms) + t_{BGE} (9ms) + t_{CLIP} (18ms) + t_{RRF} (0.05ms) \approx 30.8ms
